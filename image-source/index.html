도파관 = 입사파 + 산란파 (영상법)

평행 도체판 사이 도선의 파동을, 입사파(원본)와 산란파(영상들의 합)의 중첩으로 봅니다. 영상 개수를 늘리면 산란파가 쌓이며 도체 경계조건을 점점 만족합니다. 격자 1칸 = 1 mm. 모드 분해는 n=1–3만 표시(n≥4 미표시).

① 입사파 (원본 도선)

③ 전체장 (① + ②)

② 산란파 — 경계조건(E=0)을 만족하는 영상들의 합

④ 모드 분해 그래프 — n=1–3만 표시 (n≥4 미표시)

전파 모드는 진행하며 ≈일정, 차단 모드는 exp(−κz)로 감쇠합니다. 가로축은 위 ③ 전체장과 같은 위치입니다.

유한 N은 영상들의 근사합, N=∞는 정확한 도파관 모드 합입니다. 둘은 같은 극한으로 수렴합니다 — 영상 간섭과 모드 분해가 같은 물리임을 보여줍니다. ③ 전체장의 회색 영역은 계산 영역 밖입니다 — 모드 합은 도파관 내부 전용이며, 외부의 0은 영상 상쇄가 아닙니다.
